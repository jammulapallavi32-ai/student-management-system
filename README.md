# Student Management System

## Description
A console-based Student Management System developed using Python and MySQL. It allows users to perform CRUD operations on student records.

## Features
- Add Student
- View Students
- Search Student by ID
- Update Student
- Delete Student

## Technologies Used
- Python
- MySQL
- mysql-connector-python
- VS Code

## Database
- Database: student_db
- Table: students

## Project Structure
Student_Management_System/
├── main.py
├── db.py
├── student.py
├── README.md

## How to Run
1. Start the MySQL server.
2. Create the `student_db` database.
3. Update the MySQL password in `db.py`.
4. Run:
   ```bash
   python main.py
   ```
